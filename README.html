数独小游戏 V3.2.8

基于 V3 已验证的服务器级登录隔离架构继续升级。本版重点为现代化界面、高级技巧、渐进式三层提示、专项教学、题库后台、用户学习分析及自定义九宫格录入。

核心新增

  • 现代酷炫 UI：深色渐变、玻璃拟态、霓虹棋盘、响应式侧栏/移动导航。
  • 高级解题库：Naked/Hidden Single、Locked Candidates、Pair/Triple/Quad、X-Wing、Skyscraper、Two-String Kite、XY-Wing、XYZ-Wing、W-Wing、Simple Coloring、Swordfish、Jellyfish、Unique Rectangle Type 1，并保留搜索兜底。
  • 高级步骤安全校验：唯一解题目中，候选消除与落子在用于提示/教学前都会校验不会排除真实解。
  • 真正三层提示：第1层只给观察方向，第2层解锁技巧，第3层显示具体落子/删候选；逐层解锁不额外扣提示额度，开启一个新提示才计1次。
  • 互动教学 + 专项练习：动画高亮、候选变化、逐步播放和针对技巧的训练题。
  • 管理员题库后台：单题新增、JSON批量导入、搜索、难度过滤、启停、删除；导入时校验81位格式、合法性和唯一解。
  • 学习分析仪表盘：完成量、平均用时、最佳积分、提示使用、课程进度、各难度完成分布、最近成绩；管理员可查看系统总览。
  • 自定义数独：9×9九宫格直接录入 + 81位/9行文本输入 + TXT/JSON文件导入，三种方式互相同步。

Windows

解压到全新目录，双击 start-windows.bat，浏览器打开 http://127.0.0.1:8080。

Linux

chmod +x start-linux.sh && ./start-linux.sh

Docker

docker compose up -d --build

V3.2.5 修复

修复游戏棋盘 renderAll 错误；新增系统日志与操作审计，管理员后台可查询。

V3.2.5 细粒度权限

管理员可逐用户独立控制：正常做题、互动教学、自定义数独、题目生成器、自定义题详细分析、手工候选、自动候选、撤销/重做、三层提示、提示历史回看、游戏当前分析、全过程回放、排行榜，以及每题提示次数。

涉及服务端数据的提示与历史接口同时执行服务端鉴权；前端辅助入口按权限自动隐藏。在线用户每30秒刷新一次权限，管理员变更无需重新创建账号。
